# Cuestionario comunitario · el gallinero que queremos

Formulario web (HTML estático) de **MIA Global Consulting** para la comunidad de Fundación Armadillo.

- Preguntas tomadas del cuestionario comunitario original (PDF/DOCX en docs MIA).
- Identidad MIA (naranja `#FF914C`, negro `#1F1F1F`, blanco, Poppins, texto grande).
- Respuestas: Firestore (`cuestionario_gallinero`) + CSV descargable + WhatsApp + localStorage.
- Sin APIs de pago. Proyecto Firebase Spark: `mia-global-apps-d1cba`.

## Uso local

Abra `index.html` en un navegador o sirva la carpeta con cualquier servidor estático.
